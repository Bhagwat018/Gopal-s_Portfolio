# Gopal's Portfolio 🚀

A modern developer portfolio built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**, showcasing the work and engineering milestones of **Gopal Bhagwat** — Mobile Engineer specializing in React Native, Native Bridging (Kotlin/Swift), and Offline-First Architectures.

---

## ⚡ Tech Stack & Architecture

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Server Components & Static Site Generation)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom clay-brutalist design tokens
- **Animations**: [Framer Motion](https://www.framer.com/motion/) (Viewport scroll reveals, 3D interactive phone tilt)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Theme**: Strict Light Mode (Clean paper background with subtle dot-grid pattern)
- **Fonts**: Space Grotesk (Headings), Inter (Body), JetBrains Mono (Code/Badges) via `next/font/google`
- **Data Management**: Centralized data layer at `src/lib/data.ts`

---

## 📱 Features

- **Sticky Navigation**: Floating header with `GB` monogram, desktop pill navigation, and mobile drawer menu.
- **3D Interactive Phone Mockup**: Real-time tilt responsive to mouse movement, build status switcher, FPS target, and performance charts.
- **Continuous Tech Marquee**: Infinite looping tech stack ribbon with neon accent indicators.
- **Key Metrics & Stats**: Clay-brutal cards highlighting 3+ years experience, 4+ published production apps, and the Code Commander Award 2025.
- **Experience Timeline**: Career journey milestones and deep-dive engineering responsibilities for **5Exceptions Software Solutions** and **Ideal IT Techno**, plus Education & Awards.
- **Production Apps & NPM Packages**: Cloned cards showcasing **TruVideo**, **KickScore**, **SaveKit**, **Invoicely**, and open-source packages (`react-native-responsive-layout-kit`, `react-native-shimmer-craft`).
- **Technical Skills Bento**: 4 categorized stacks with highlighted pills.
- **Interactive Contact Banner**: High-contrast indigo container with morphing blobs, direct mailto CTA, and direct links to GitHub and LinkedIn.

## 🛠️ Getting Started

### Prerequisites

- Node.js 18+ (tested on Node v24)
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Bhagwat018/Gopal-s_Portfolio.git

# Navigate into the project directory
cd Gopal-s_Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### Building for Production

```bash
npm run build
npm start
```
